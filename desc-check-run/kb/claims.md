## How to read the table

- **Type** is one of: fact about a text / fact about a tool / causal explanation / promise about the rewrite. "(evaluative)" marks a judgement of quality. Checker findings are all "fact about a tool".
- **Evidence in source** says whether the source text itself gave support: `examples quoted` (it quoted README lines), `partial`, or `none (assumed)`.
- **How it could be tested** uses only files in RUN, or says "not testable here" and why. "excerpt" means `fixtures/readme_excerpt.md` (16 lines); the full README is not in RUN, so a claim about "the README" or "every paragraph" can only be tested on the excerpt.
- **Decision-relevant?** yes only if the claim, were it false, would change what this run rebuilds, how time or accuracy is measured, which test cases are used, or which design is chosen (BRIEF sections 1-3). Style-pattern claims are "no" because BRIEF section 2 puts text generation and restyling out of scope.
- Flags: **T1-T5** = tensions between claims (list below). **GAP** = inference that rests on something the source does not show.
